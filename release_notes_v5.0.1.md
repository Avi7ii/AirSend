# AirSend v5.0.1

## 中文

- 双端默认启用 **Full Access**，安装后即可直接传输，无需先确认或建立信任；仍可手动切换为 Trusted Only 或 Off。
- 修复旧版 `Ask` 接收策略残留，并自动迁移已有默认配置。

> 若软件内更新失效，请卸载旧版后从本页重新安装最新版。

## English

- **Full Access** is now the cross-platform default, so transfers work immediately after installation without prior confirmation or trust setup; Trusted Only and Off remain available.
- Removes the legacy `Ask` policy from the UI and automatically migrates existing default configurations.

> If the in-app update fails, uninstall the previous version and reinstall the latest release from this page.
