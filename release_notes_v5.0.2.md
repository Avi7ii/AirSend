# AirSend v5.0.2

## 中文

- 新增双端中英文切换，并优化 macOS 玻璃界面、开场动画与 Quick Look 预览。
- 改进 Android 状态提示；模块现可通过 Magisk、KernelSU 和 APatch 自动检查完整更新。

> 若软件内或模块管理器更新失败，请卸载旧版后从本页重新安装最新版。

## English

- Adds Chinese and English switching, with refined macOS glass UI, entrance animations, and Quick Look previews.
- Improves Android status guidance and enables full-module update checks in Magisk, KernelSU, and APatch.

> If in-app or module-manager updates fail, uninstall the previous version and reinstall the latest release from this page.
